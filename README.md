# Schiessbuch

Eigenständige App zum Erfassen von Schiessresultaten und Fotos der Papierscheiben.
Alle Übungen und Fotos werden nur auf dem Telefon gespeichert (in der lokalen
Datenbank des Browsers). Es wird nichts hochgeladen.
Nach der Installation funktioniert die App auch offline.

Installation
------------
1. Lade diesen Ordner einmal auf einen statischen Webhost mit https,
   z. B. GitHub Pages oder Netlify. Alle Dateien unverändert hochladen.
   Der Host liefert nur die App-Dateien aus. Deine Daten gelangen nie dorthin.
2. iPhone: Adresse in Safari öffnen, Teilen > Zum Home-Bildschirm.
   Android: Adresse in Chrome öffnen, Menü > App installieren
   (oder Zum Startbildschirm hinzufügen).
3. Öffne die App immer über das Symbol auf dem Home-Bildschirm. Dort sind deine Daten.
4. Speichere regelmässig ein Backup. Die Backup-Datei enthält alle Übungen
   und Fotos. Mit «Backup wiederherstellen» lädst du sie auf ein neues Telefon.

Hinweis: Wenn du die App vom Home-Bildschirm löschst oder die Website-Daten
von Safari/Chrome löschst, werden die gespeicherten Übungen gelöscht.
Bewahre ein Backup auf.

ENGLISH
-------
A standalone app for recording shooting results and photos of paper targets.
All sessions and photos are stored only on the phone (in the browser's local
database). Nothing is uploaded anywhere. Works offline once installed.

Installation
------------
1. Put this folder online once, on any static web host with https, e.g.
   GitHub Pages or Netlify. Upload all files exactly as they are.
   The host only serves the app files. Your data never goes there.
2. iPhone: open the address in Safari, tap Share > Add to Home Screen.
   Android: open the address #in Chrome#, tap the menu > Install app
   (or Add to Home screen).
3. Always open the app from the home-screen icon. That's where your data lives.
4. Use "Save backup" regularly. The backup file contains all sessions and
   photos. "Restore backup" loads it on a new phone.

Note: deleting the app from the home screen, or clearing Safari/Chrome
website data, deletes the stored sessions. Keep a backup.
